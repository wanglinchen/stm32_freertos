APL
main.c：health → 时钟 → periph(两级) → 起 2 任务 → 调度器；periph 失败不 panic
FML
led_blink / button 两个任务；设备不就绪即降级（跳过设备、只喂健康心跳）
BSL
const 设备表（生成期按 level+order 排序）+ 类型化 ops + 日志出口判 UART 就绪
OSL
启动/看门狗/tick · panic(.noinit 140 B) · health(堆字节 + 2 栈槽 word)
HAL
ST HAL + CMSIS（vendored）；apl 不含 hal 头
已与 Zephyr 对齐对照物
设备注册表DEVICE_DT_DEFINE 链接段
init 分级 + 顺序SYS_INIT(level, priority)
api 编译期类型DEVICE_API
device_is_ready同
失败不阻断、可查状态device_init_status（本工程更严：跨级也跑完）

仍然落后的外围子系统

维度本工程
日志 编译期 3 级、同步阻塞、无 ring 缺「故障前 N 条」
栈可见性 动态栈在 16 KB heap，只能上板测 编译期不可算
异步执行体 configUSE_TIMERS=0，无 work 队列 无事件驱动载体
内存保护 单特权级 + canary(2) 无 MPU 隔离
绑定校验 只查 5 条写死的 compatible 可升级全量双向
测试 有断言自证，无 host 单测 强项不重叠
升级 / 存储 无 NVS、无 bootloader 实验室板可接受
文档一致性 doc-contract / count / reference 三道门禁 比 Zephyr 更严

结论：设备模型已不落后，落后的是日志、栈可见性、异步执行体、MPU、升级能力。

P0 · 各半天 · 纯判据

1. init 顺序的依赖判据

现状 order 是唯一真源，靠人维护。beep 改成 25 仍全绿，板上蜂鸣器先于 I2C init，错误被静默丢弃。

建议 断言 beep.pcf8574 > pcf8574 > i2c_gpio，且同级 order 不重复。

P0 · 各半天 · 纯判据

2. binding ↔ DTS 全量覆盖

现状 只检查 5 条写死的 compatible；新增第 7 个设备时漏一条不会被发现。

建议 双向差集：binding 有 DTS 无 → 无消费者；DTS 有 binding 无 → 不进注册表。

P0 · 半天 · 小改代码

3. 设备「必需 / 可选」显式化

现状 「beep 可选」只写在 fml 的 if 里；bsl_board_periph_init() 的返回值被 (void) 丢弃，first_err 是死值。

建议 binding 加 optional → 只聚合必需设备的失败 → main 消费它。

P1 · 1~2 天 · 改代码

1. 日志 ring + panic 快照

现状 一次 IWDG 复位后只有 140 B record 说明「哪条路炸的」，说明不了「炸之前发生了什么」。

建议 64~128 B ring（模块 + 事件码 + tick），panic 时连同记录落盘。

P1 · 1~2 天 · 改代码

2. 任务栈静态化

现状 configSUPPORT_STATIC_ALLOCATION=0，栈在 ucHeap，门禁无法断言总栈量。

建议 开静态分配 + 每任务 static StackType_t → map 可算、可加总量上限判据。

P1 · 半天 · 改代码

3. init 耗时观测

现状 只记成功/失败。本轮才把 I2C ACK 窗口从 30 µs 修到 400 µs，「init 里等了多久」没有任何读数。

建议 每次 init 前后取 tick，超阈值打 ERR 并入 health。

条件触发项（现在不做）

建议触发条件为什么现在不做
延后初始化（≈ DEVICE_DEFERRED_INIT）单设备 init > 10 ms，或需内核起来后再探总线6 个设备都是寄存器写，全 init 在百 µs 级
work / 软件定时器（≈ k_work）出现长按、双击、蜂鸣器节奏、迟滞重试configUSE_TIMERS=0 是主动选择；加 timer 会带进 prvTimerTask 栈
MPU / 硬件栈保护产品化交付、多人并行改代码单特权级 + canary；收益在「隔离野指针」，当前风险低
判据函数的 host 单测判据出现二进制/数值解析类逻辑51 组破坏自证已覆盖「会不会漏红」；当前多是字符串匹配
NVS / MCUboot 升级交付客户、需现场升级实验室板插调试器即可；引入 bootloader 会动链接脚本与启动流程
