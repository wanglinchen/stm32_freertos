# STM8 和 STM32 产品选型手册

来源：`STM8和STM32产品选型手册.pdf`，ST 选型册，2015 年 8 月印于中国，56 页。正文是英文。封面和封底是中文站点 `www.stmcu.com.cn`。

册子按系列分成产品线，每一线下面是料号、Flash、RAM、封装、定时器、ADC、通信口、电压、电流和温度。版面是多栏表格，抽成纯文本后列会对错。下面按系列和产品线整理这本册子里的划分；某个具体封装有多少引脚，仍查原 PDF 对应页。

这是 2015 年的产品范围。之后的 G 系列、H7、新的 F4 料号不在这本册子里。

## 1 怎么选

第 3 页把产品分成三档：

| 档 | STM32 | STM8 |
| --- | --- | --- |
| 主流 | F0（Cortex-M0）、F1（Cortex-M3）、F3（Cortex-M4，带 DSP 和 FPU） | STM8S |
| 高性能 | F2（Cortex-M3）、F4（Cortex-M4，带 DSP 和 FPU）、F7（Cortex-M7） | — |
| 超低功耗 | L0（Cortex-M0+）、L1（Cortex-M3）、L4（Cortex-M4） | STM8L |
| 汽车 | — | STM8A：STM8AF 主流汽车，STM8AL 超低功耗汽车 |

本工程用的 STM32F429 在高性能这一档，属于 F429/F439 产品线：在 F427/F437 的配置上增加 TFT LCD 控制器，内核 180 MHz。

## 2 料号怎么读

第 54 页。以 `STM32F051R8T6` 为例，从左到右是：

| 字段 | 例子 | 含义 |
| --- | --- | --- |
| 家族 | STM32 / STM8 | 32 位或 8 位 |
| 类型 | F、L、S、A、T、W | Foundation、超低功耗、标准、汽车、触摸、无线。F 在 STM32 里就是 F 系列 |
| 特性三位 | 051、103、303、407、152 | 产品线。051 入门，103 基础，303 在 103 上加 DSP 和模拟，407 高性能带 DSP 和 FPU，152 超低功耗。册子写明这不是完整列表 |
| 引脚数 | R | 见下表 |
| Flash | 8 | 见下表，单位 KB |
| 封装 | T | 见下表 |
| 温度 | 6 | 见下表 |
| 选项 | 无字母、Y、TR 等 | 无字母通常是 BOR 打开且标准自举。Y 是晶圆版本。TR 是卷带。还有 FastROM、关 BOR、关 RTC 等后缀，随系列变化 |

Flash 代码：

| 代码 | KB | 代码 | KB |
| --- | --- | --- | --- |
| 4 | 16 | C | 256 |
| 6 | 32 | D | 384 |
| 8 | 64 | E | 512 |
| B | 128 | G | 1024 |
| Z | 192 | I | 2048 |

A 在 STM8A 上表示 96 KB，在其它系列上常表示 128 KB。册子对 A 的注是「仅 STM8A 为 96，否则 128」。

引脚代码（STM8 与 STM32 共用这张表）：

| 代码 | 引脚 | 代码 | 引脚 |
| --- | --- | --- | --- |
| D | 14 | V | 100 |
| Y | 20（STM8） | Q | 132 |
| F | 20（STM32） | Z | 144 |
| E | 24、25 | A | 169 |
| G | 28 | I | 176，或 176+25 |
| K | 32 | B | 208 |
| T | 36 | N | 216 |
| H | 40 | X | 256 |
| S | 44 | C | 48、49 |
| R | 64、66 | O | 90 |

封装代码：T 是 QFP，U 是 UFQFPN，V 是 VFQFPN，Y 是 WLCSP，H 是 LFBGA/TFBGA，I/J/K 是不同球距的 UFBGA，M 是 SO，P 是 TSSOP，B 是塑料 DIP。

温度代码：6 和 A 是 -40 °C 到 +85 °C，7 和 B 是到 +105 °C，3 和 C 是到 +125 °C，D 是到 +150 °C。

因此 `STM32F429IG` 读成：F4 系列、429 这一线、176 脚、1024 KB Flash。温度和封装还要看后面的字母，册子里的完整订购码比这六个字符长。

## 3 STM32 各系列在册子里的产品线

表格里的 USB「HS」都要外接 ULPI PHY，片上没有高速 PHY。标成 `3+2` 的串口是 3 个 USART 加 2 个 UART。UART 有 LIN；USART 另外有 IrDA、ISO 7816 和调制解调器控制线。

### 3.1 F0，Cortex-M0，入门，48 MHz

| 产品线 | 册子中的定位 |
| --- | --- |
| F0x0 Value | 48 MHz |
| F051 | 48 MHz，带 DAC |
| F0x1 | 48 MHz |
| F0x2 | 48 MHz，带 USB 和 CAN |
| F0x8 | 48 MHz，带 USB |

### 3.2 F1，Cortex-M3，基础

| 产品线 | 册子中的定位 |
| --- | --- |
| F100 Value | 24 MHz |
| F101 Access | 36 MHz |
| F102 USB Access | 48 MHz |
| F103 Performance | 72 MHz |
| F105/F107 Connectivity | 72 MHz，互联型 |

### 3.3 F2，Cortex-M3，高性能，120 MHz

| 产品线 | 册子中的定位 |
| --- | --- |
| F2x5 | USB OTG（全速，高速需外接 PHY），带加密/散列的型号另标 |
| F2x7 | 两个 USB OTG（全速/高速）、摄像头接口，带加密/散列的型号另标 |

### 3.4 F3，Cortex-M4，混合信号，带 DSP 和 FPU，72 MHz

| 产品线 | 册子中的定位 |
| --- | --- |
| F301 | 高级定时器，12 位 ADC，5 MSPS |
| F302 | 同上 |
| F303 | 最多 16 KB CCM SRAM，高级定时器，12 位 ADC，5 MSPS |
| F373 | 16 位 Σ-Δ ADC |
| F3x4 | 高分辨率定时器 |
| F3x8 | 稳压器可关断，1.8 V |

### 3.5 F4，Cortex-M4，高性能，带 DSP 和 FPU

加密/散列只出现在 F415、F417、F437、F439、F479。同一线里不带这些数字的型号没有加密模块。F429 没有，F439 有。

| 产品线 | 主频 | 册子中的定位 |
| --- | --- | --- |
| F401 | 84 MHz | 只有 USB OTG 全速。Stop 典型 10 µA |
| F411 | 100 MHz | 批量采集模式（BAM），USB OTG 全速。Stop 典型 9 µA |
| F405/F415 | 168 MHz | USB OTG 全速/高速，F415 有加密/散列 |
| F407/F417 | 168 MHz | 在上一条上增加第二个 USB OTG、摄像头接口和以太网。F417 有加密/散列 |
| F427/F437 | 180 MHz | 两个 USB OTG、摄像头、SDRAM 接口、双区 Flash。F437 有加密/散列 |
| F429/F439 | 180 MHz | 与 F427/F437 相同，再加 TFT LCD 控制器。F439 有加密/散列 |
| F446 | 180 MHz | 册子只标了主频，没有写 LCD |
| F4x9（F469/F479） | 180 MHz | 带 MIPI 接口。F479 有加密/散列 |

F429/F439 这一线在册子里的公共资源配置，和 F427/F437 对齐：12 个 16 位定时器加 2 个 32 位定时器，两个看门狗、RTC、24 位递减计数器，ADC 为 12 位、DAC 两路，SPI 最多 6 个，SAI、I2S、I2C，串口写成 4+4，两个 CAN 2.0B，SDIO，以太网写着 Yes。运行电流约 208 µA/MHz，最低功耗模式约 1.7 µA，电压约 1.7 V 到 3.6 V，温度 -40 °C 到 +105 °C。Flash 从 512 KB 到 2048 KB，RAM 256 KB。封装从 LQFP100 到 BGA。具体一行的引脚数以 PDF 第 25–26 页为准。

### 3.6 F7，Cortex-M7，高性能

册子这一版主要写了带 LCD-TFT 控制器的 F7x6，216 MHz。页数少，只有当时刚出来的型号。

### 3.7 L0，Cortex-M0+，超低功耗，32 MHz

| 产品线 | 定位 |
| --- | --- |
| L0x1 | Access |
| L0x2 | 带 USB |

### 3.8 L1，Cortex-M3，超低功耗，32 MHz

| --- | --- |

这一版只有 L4x6，80 MHz。后来的 L4 全系不在册子里。

## 4 STM8

内核是 8 位。和 STM32 的差别是多数型号带数据 EEPROM，主频是 16 MHz 或 24 MHz。

| 系列 | 产品线 | 定位 |
| --- | --- | --- |
| STM8S 主流 | S003/S005/S007 | Value，16 MHz |
| STM8S | S103/S105 | Access，16 MHz |
| STM8S | S207/S208 | Performance，24 MHz |
| STM8AF 汽车 | AF52 | CAN 和 LIN，最高 24 MHz |
| STM8AF | AF62 | LIN，最高 24 MHz |
| STM8AL 汽车超低功耗 | AL31 | 标准低功耗，16 MHz |
| STM8AL | AL3L | 带 LCD（4×17 或 4×28），16 MHz |
| STM8L 超低功耗 | L101 | 入门，16 MHz |
| STM8L | L051/L052 | Value，16 MHz |

## 5 读表时用到的缩写

第 53 页是缩写和封装全称。读选型表时常用的是：

| 缩写 | 含义 |
| --- | --- |
| SAI | 串行音频接口 |
| I2S | 音频用的集成电路互联声音接口 |
| SDIO | SD 卡接口 |
| MAC | 这里的以太网列是 10/100 媒体访问控制器 |
| WDG | 看门狗。表里的「2x WDG」一般是独立看门狗加窗口看门狗 |
| LQFP / UFBGA / WLCSP / UFQFPN | 四种最常见的封装 |
| ULPI | 高速 USB 的外接 PHY 接口 |

脚注：高速 USB 必须外接 PHY。加密/散列只在第 3.5 节列出的那些型号上。
