# 开发环境配置

目标 MCU：**STM32F429IGT6**（Cortex-M4，硬浮点）。本文说明 Linux / Windows 依赖、环境变量与本机构建。

## 0. build 脚本（当前文件名）

| 脚本 | 作用 |
|------|------|
| `build/create-project.py` | 生成 Kconfig/Makefile；子命令 `update` · `verify` · `build` · `clean` |
| `build/install-toolchain.py` | 安装 `tool/` 下交叉工具链；Windows 另支持 `--make-only` |
| `build/set-buildenv.py` | 解析工具链路径；`--check`；`--print bash\|powershell\|json` |

## 1. 依赖一览

| 组件 | Linux | Windows |
|------|--------|---------|
| Python 3 | 系统 `python3` | 系统安装，`PATH` 优先于 `WindowsApps\python.exe` |
| GNU Make | `sudo apt install make` | **工程内** `tool\win_x86_64\bin\make.exe`（§2.2） |
| Arm 交叉工具链 | `tool/linux_x86_64/` | `tool/win_x86_64/` |

### 1.1 Windows 本机工具目录

本机 `python build/create-project.py build` 使用 **`tool\win_x86_64\bin`**（见 `tool/.gitignore`）：

```text
tool\win_x86_64\bin\
  arm-none-eabi-gcc.exe     ← install-toolchain.py
  make.exe                  ← install-toolchain.py --make-only（MSYS 包）
  sh.exe, mkdir.exe, rm.exe ← 自 Git / MSYS2 的 usr\bin 只读复制
  msys-*.dll
```

- **`build/set-buildenv.py`** / **`build`** 会把该 `bin` 置于 **PATH 最前**；Windows 上 **`make.exe` 仅从此目录调用**。
- MSYS 临时目录：**`out\msys-tmp`**（`TMP`/`TEMP`）；**`build` 成功结束后自动删除**；失败时可能保留。
- **`workspace\msys-tmp` 已废弃**，若存在可手动删除。
- 可选：WSL 构建用 `tool/linux_x86_64/`，与 Windows 目录互不替代。

## 2. 安装工具链与本机工具

### 2.1 交叉工具链

```powershell
python build/install-toolchain.py
```

| 系统 | 目录 | 包 |
|------|------|-----|
| Linux x86_64 | `tool/linux_x86_64/` | `.tar.xz` |
| Windows | `tool/win_x86_64/` | `.zip`（mingw-w64-i686） |

- 缓存：`tool/.cache/`
- 版本：`TOOLCHAIN_VERSION` 或 `--version 13.3.rel1`
- 勿长期把未解压 `.zip` 放在 `win_x86_64/`；可移到 `tool\.cache\` 后重跑安装脚本

### 2.2 Windows：`make` 与 shell 工具

**不在 Git / MSYS2 安装目录写入任何文件。** 只从 **`usr\bin` 只读复制**到 `tool\win_x86_64\bin`；`make.exe` 由脚本下载 MSYS 包（若尚未存在）。

```powershell
python build/install-toolchain.py --make-only --from "D:\ExPrograms\DevelopTool\Git\usr\bin"
# 或 MSYS2：
python build/install-toolchain.py --make-only --from "D:\ExPrograms\DevelopTool\msys64\usr\bin"
```

环境变量（省略 `--from` 时参与自动查找，**列表顺序优先**）：

```powershell
$env:STM32_GIT_USR_BIN = "D:\ExPrograms\DevelopTool\msys64\usr\bin"
python build/install-toolchain.py --make-only
```

自动候选还包括 `D:\ExPrograms\DevelopTool\Git\usr\bin`、常见 `Program Files\Git\usr\bin` 等。

检查：

```powershell
python build/set-buildenv.py --check
```

## 3. 环境变量

| 变量 | 含义 |
|------|------|
| `STM32_TOOLCHAIN_ROOT` | 如 `...\tool\win_x86_64` |
| `STM32_TOOLCHAIN_PREFIX` | `...\bin\arm-none-eabi-` |
| `STM32_GIT_USR_BIN` | 供 **install-toolchain** 定位 `usr\bin`（Git 或 MSYS2） |
| `PATH` / `Path` | `build` 时前置 `tool\...\bin` |
| `TOOLCHAIN_VERSION` | 安装脚本工具链版本 |

`create-project.py build` 内部会 `apply` 上述环境，一般无需手设。

### Linux（示例）

```bash
eval "$(python3 build/set-buildenv.py --print bash)"
python3 build/set-buildenv.py --check
```

### Windows（示例）

```powershell
python build/set-buildenv.py --print powershell | Invoke-Expression
python build/set-buildenv.py --check
```

## 4. 构建与验证

```bash
python3 build/create-project.py update
python3 build/create-project.py verify
python3 build/create-project.py build
python3 build/create-project.py clean
```

Windows 将 `python3` 换为 `python`。产物：`out/target/stm32-freertos.{elf,hex,bin}` 与各 `lib*.a`。

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| `ModuleNotFoundError: setenv` | 使用 `set-buildenv.py` / `create-project.py`，勿再引用已删除的旧脚本名 |
| 缺少 `make.exe` / `sh.exe` | `install-toolchain.py --make-only --from "<usr\bin>"` |
| `workspace\msys-tmp` 仍存在 | 旧版残留，可删；现用 `out\msys-tmp` |
| WSL 与 Windows 共用工程 | 两套 `tool/*` 分别维护 |

更多约定见 [.skills/工程规格.md](../.skills/工程规格.md)。
